# About Me:
<br>Hey, I’m Abhiram 👋</br>
I’m a tech enthusiast who enjoys breaking things to understand how they work. Right now, I only know the basics of cybersecurity — not a lot — but I do understand core security concepts and how different pieces fit together.<br>I
enjoy working with Linux (Kali is home 🐧) and learning through platforms like TryHackMe and Hack The Box. So far, I’ve studied and practiced fundamentals of networking, basic pentesting, web & API pentesting, Android app pentesting, Active Directory (basic), SOC fundamentals, and a little about LLMs. Most of this learning comes from the <b>ADIS (Advanced Diploma in Information Security) course at Offenso Hackers Academy.</b> <br>
I’ve covered a wide range of topics, even though my hands-on depth is still at a beginner level. I use this website as a space to put what’s on my mind and what I want to build. Whatever I find interesting or useful, I add to my projects section. I don’t code everything from scratch — I often use AI tools to help turn ideas into working pages while I focus on learning and experimenting.<br>
